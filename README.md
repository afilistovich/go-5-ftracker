# Модуль фитнес-трекера

**go-5-ftracker** — Модуль обрабатывает данные тренировки — бег, спортивную ходьбу — и возвращает сводку: тип тренировки, её длительность, пройденную дистанцию, среднюю скорость и количество сожжённых калорий. Реализован на интерфейсах, структурах, методах и эмбеддинге.

## Входные данные

- количество шагов (бег, ходьба) или гребков (плавание);
- длительность тренировки;
- вес и рост пользователя;
- для плавания — длина бассейна и число проплытых бассейнов.

## Как считаются метрики

| Тренировка | Дистанция, км | Средняя скорость, км/ч | Калории |
|---|---|---|---|
| Бег | шаги × 0.65 / 1000 | дистанция / время (ч) | (18 × скорость + 1.79) × вес / 1000 × время (мин) |
| Ходьба | шаги × 0.65 / 1000 | дистанция / время (ч) | (0.035 × вес + скорость²(м/с) / рост(м) × 0.029 × вес) × время (мин) |
| Плавание | (бассейн × заплывы) / 1000 | дистанция / время (ч) | (скорость + 1.1) × 2 × вес × время (ч) |

## Структура проекта

```
.
├── cmd/tracker/          # точка входа
├── internal/             # логика модуля; рядом с файлами лежат *_test.go
├── go.mod, go.sum
└── .github/workflows/    # автозапуск тестов
```

## Тестирование

Файлы `*_test.go` рядом с реализацией содержат юнит-тесты и не подлежат изменению — их прогоняет GitHub Actions при каждом пуше.

```bash
go mod tidy
go test -v ./...
```

## Запуск

```bash
git clone https://github.com/afilistovich/go-5-ftracker.git
cd go-5-ftracker
go run ./cmd/tracker
```
